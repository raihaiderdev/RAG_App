Task Description

LMs don't know your private data — that's where Retrieval-Augmented Generation (RAG) comes in. It's the technique behind almost every "chat with your PDF" tool you've seen. You'll build a small pipeline that lets an AI answer questions using a document you give it, instead of guessing from its training data.

Tech/Concepts covered: RAG (Retrieval-Augmented Generation), embeddings, vector search, chunking, tools like LangChain, LlamaIndex, or a no-code option (NotebookLM / Claude Projects / custom GPTs) if coding is too heavy for this stage.

  • Pick a document (a PDF report, your resume, or class notes — 3–10 pages is fine)
  • Choose your approach: code it with LangChain/LlamaIndex + embeddings, OR use a no-code tool like NotebookLM, Claude Projects, or a custom GPT with file upload
  • Make it answer at least 3 meaningful questions from the document
  • Submit a short demo (screenshot or screen recording) showing it working
